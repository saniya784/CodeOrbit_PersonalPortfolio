# CodeOrbit Personal Portfolio Website

A responsive personal portfolio website developed as part of the
**CodeOrbit Technologies Internship – Personal Portfolio Website Task**.

The portfolio showcases my introduction, technical skills, projects,
education, and contact information through a clean and responsive user
interface.

## 📌 Project Overview

This personal portfolio website is designed to provide a professional online
presence and showcase my skills and projects.

The website includes:

- About Me
- Skills
- Projects
- Education
- Contact Information
- Responsive navigation
- Responsive design for mobile, tablet, and desktop screens
- Interactive UI elements

## ✨ Features

### About Section

Introduces my background, interests, and career goals.

### Skills Section

Displays my technical skills and technologies that I have worked with.

### Projects Section

Showcases selected projects with descriptions and relevant technologies.

### Education Section

Provides information about my academic background.

### Contact Section

Allows visitors to view my contact information and get in touch with me.

### Responsive Design

The website adapts to different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/CodeOrbit_PersonalPortfolio.git
```

### 2. Navigate to the Project

```bash
cd CodeOrbit_PersonalPortfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
